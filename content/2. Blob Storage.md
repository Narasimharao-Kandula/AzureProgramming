# Azure Blob Storage — Complete Guide

**Project Title:** Cloud Service with WebRole Demonstrating Azure Blob Storage
**Runtime:** .NET 8.0 LTS
**Language:** C#
**IDE Support:** Visual Studio Community 2022 / Visual Studio 2026 / Visual Studio 2026 Insiders
**Method:** Real Azure Storage Account (no local emulator)

**Features:**
- Upload images to Azure Blob Storage
- Display all uploaded images in a gallery
- Download any image to your computer
- Delete any image from the gallery and cloud

## PART 1: Create Azure Storage Account (Cloud Side)

### Step 1.1 — Sign In to Azure Portal

1. Open your web browser.
2. Navigate to: **https://portal.azure.com**
3. Sign in with your Microsoft/Azure credentials.

### Step 1.2 — Start Creating a Storage Account

1. Once on the Azure Portal home page, look at the **top-left corner** of the page.
2. Click the hamburger menu (three horizontal lines) if the sidebar is collapsed.
3. Click **"Create a resource"**.
4. In the **search marketplace** box, type: `Storage Account`
5. Click on the **Storage Account** result (publisher: Microsoft).
6. Click the **Create** button.

### Step 1.3 — Configure the Basics Tab

You will now see a multi-tab form. The **Basics** tab is shown by default.

Fill in the following fields:

| Field | Action | Example Value |
|---|---|---|
| **Subscription** | Click the dropdown and select your active Azure subscription | `Azure subscription 1` |
| **Resource Group** | Click **"Create new"** → A popup appears → Type: `LabExperiments` → Click **OK** | `LabExperiments` |
| **Storage account name** | Type a unique name (lowercase letters and numbers only, 3–24 characters) | `blobstorage2026` |
| **Region** | Click the dropdown → Select the datacenter **closest to your location** | `(US) East US` or your nearest region |
| **Performance** | Leave as **Standard** (default) | `Standard` |
| **Redundancy** | Click the dropdown → Select **Locally-redundant storage (LRS)** | `Locally-redundant storage (LRS)` |

> **Do NOT click "Review + create" yet.** Just verify the above fields are correct. Leave all other tabs (Advanced, Networking, Data protection, Encryption, Tags) at their **default values**.

### Step 1.4 — Create the Storage Account

1. Click the **"Review + create"** button at the bottom.
2. Wait for validation to complete. You will see a **green checkmark** with "Validation passed".
3. Click the **Create** button.
4. Wait for the deployment to finish (usually 1–2 minutes).
5. You will see **"Your deployment is complete"** with a green checkmark.

### Step 1.5 — Get the Connection String

This connection string is the key that allows your application to connect to your cloud storage.

1. Click the **"Go to resource"** button on the deployment complete page.
   - (Or later: find your storage account by searching its name in the top Azure Portal search bar.)
2. On the left-side menu of your Storage Account page, find and click **"Security + networking"** to expand it.
3. Under that, click **"Access keys"**.
4. You will see two keys: **key1** and **key2**.
5. Under the **key1** section, find the row labeled **"Connection string"**.
6. Click the **"Show"** button next to the connection string value.
7. Click the **copy icon** (two overlapping squares) next to the connection string.
8. **Paste it into Notepad or any text editor and save the file.** You will need this in Part 3.

> Your connection string will look like this (your values will differ):
> `DefaultEndpointsProtocol=https;AccountName=blobstorage2026;AccountKey=aBcDeFgHiJkLmNoPqRsTuVwXyZ0123456789==;EndpointSuffix=core.windows.net`

**IMPORTANT:** Keep this connection string secret. Do not share it or commit it to public code repositories.

2. **Double-click** `appsettings.json` to open it in the editor.
3. **Select all** text in the file (Ctrl+A) and **delete** it.

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "AzureBlobStorage": "PASTE_YOUR_CONNECTION_STRING_HERE"
```

5. **Replace** the text `PASTE_YOUR_CONNECTION_STRING_HERE` with the connection string you saved in **Step 1.5**. Make sure the entire connection string is inside the double quotes and is on one line with no line breaks.

### Step 3.4 — Create the Controller (Application Logic)

**File:** `Controllers/BlobController.cs` (new file — you create it)

1. In **Solution Explorer**, find the **Controllers** folder under `BlobWebRole`.
2. **Right-click** on the **Controllers** folder.
3. Hover over **Add** → click **Controller...**.
4. A dialog appears with controller templates. Select:
   - **Template:** `MVC Controller - Empty`
5. Click **Add**.
6. In the name field at the bottom, type: `BlobController`
7. Click **Add**.
8. A new file opens with some default code. **Select all** (Ctrl+A) and **delete** everything.
9. **Paste** the following code:

```csharp
using Microsoft.AspNetCore.Mvc;
using Azure.Storage.Blobs;
using Azure.Storage.Sas;
using BlobWebRole.Models;

namespace BlobWebRole.Controllers
{
    public class BlobController : Controller
    {
        private readonly string _connectionString;
        private const string ContainerName = "democontainer";

        public BlobController(IConfiguration config)
            => _connectionString = config.GetConnectionString("AzureBlobStorage")!;

        private BlobContainerClient GetContainer()
        {
            var container = new BlobServiceClient(_connectionString)
                .GetBlobContainerClient(ContainerName);
            container.CreateIfNotExists();
            return container;
        }

        public async Task<IActionResult> Index()
        {
            var container = GetContainer();
            var blobs = new List<BlobModel>();

            await foreach (var blobItem in container.GetBlobsAsync())
            {
                var blobClient = container.GetBlobClient(blobItem.Name);
                blobs.Add(new BlobModel
                {
                    FileName = blobItem.Name,
                    FileUrl = blobClient.GenerateSasUri(
                        BlobSasPermissions.Read,
                        DateTimeOffset.UtcNow.AddHours(1)).ToString()
                });
            }

            return View("~/Views/Home/Index.cshtml", blobs);
        }

        [HttpPost]
        public async Task<IActionResult> Upload(IFormFile file)
        {
            if (file == null || file.Length == 0)
                return RedirectToAction("Index");

            try
            {
                var container = GetContainer();
                var blob = container.GetBlobClient(file.FileName);

                using var stream = file.OpenReadStream();
                await blob.UploadAsync(stream, overwrite: true);

                TempData["Message"] = "Upload Successful!";
            }
            catch (Exception ex)
            {
                TempData["Message"] = $"Error: {ex.Message}";
            }

            return RedirectToAction("Index");
        }

        public async Task<IActionResult> Download(string fileName)
        {
            var container = GetContainer();
            var blob = container.GetBlobClient(fileName);
            var response = await blob.DownloadAsync();

            return File(
                response.Value.Content,
                response.Value.ContentType,
                fileName);
        }

        [HttpPost]
        public async Task<IActionResult> Delete(string fileName)
        {
            try
            {
                var container = GetContainer();
                await container.DeleteBlobAsync(fileName);
                TempData["Message"] = $"Deleted '{fileName}' successfully.";
            }
            catch (Exception ex)
            {
                TempData["Message"] = $"Error deleting: {ex.Message}";
            }

            return RedirectToAction("Index");
        }
    }
}
```

10. Press **Ctrl+S** to save.

> **Line-by-line explanation:**
>
> | Code | Purpose |
> |---|---|
> | `using Microsoft.AspNetCore.Mvc;` | Imports MVC framework classes (Controller, IActionResult, etc.) |
> | `using Azure.Storage.Blobs;` | Imports Azure Blob SDK classes (BlobServiceClient, BlobContainerClient, etc.) |
> | `using Azure.Storage.Sas;` | Imports SAS (Shared Access Signature) classes for generating secure temporary URLs |
> | `using BlobWebRole.Models;` | Imports your BlobModel class |
> | `private readonly string _connectionString;` | Stores the connection string. Set once, never changes |
> | `private const string ContainerName = "democontainer";` | The name of the blob container (like a folder). Defined once to avoid typos |
> | `public BlobController(IConfiguration config)` | **Constructor** — ASP.NET Core automatically provides the configuration when creating this controller |
> | `=> _connectionString = config.GetConnectionString("AzureBlobStorage")!;` | Reads the connection string from `appsettings.json` using the key name `AzureBlobStorage` |
> | `private BlobContainerClient GetContainer()` | **Helper method** — creates or gets the container. Used by all four actions to avoid code duplication |
> | `new BlobServiceClient(_connectionString)` | Creates a client object that connects to your Azure Storage Account |
> | `.GetBlobContainerClient(ContainerName)` | Gets a reference to the container named `democontainer` |
> | `container.CreateIfNotExists()` | If the container doesn't exist, creates it. If it does exist, does nothing |
> | **`Index()` action** | |
> | `await foreach (var blobItem in container.GetBlobsAsync())` | Loops through every file stored in the container (async enumeration) |
> | `container.GetBlobClient(blobItem.Name)` | Gets a reference to one specific blob (file) |
> | `blobClient.GenerateSasUri(BlobSasPermissions.Read, DateTimeOffset.UtcNow.AddHours(1))` | Generates a secure temporary URL that allows read access for 1 hour, then expires |
> | `return View("~/Views/Home/Index.cshtml", blobs);` | Renders the Index page and passes the list of blobs to it |
> | **`Upload()` action** | |
> | `[HttpPost]` | Only responds to POST requests (form submissions) |
> | `public async Task<IActionResult> Upload(IFormFile file)` | `file` matches `name="file"` in the HTML form. `IFormFile` is ASP.NET's type for uploaded files |
> | `blob.UploadAsync(stream, overwrite: true)` | Uploads the file to Azure. `overwrite: true` means if a file with the same name exists, replace it |
> | `TempData["Message"] = "Upload Successful!";` | Stores a message that survives the redirect (unlike ViewBag which does not) |
> | `return RedirectToAction("Index");` | Redirects to the Index action so the full gallery reloads with the new image included |
> | **`Download()` action** | |
> | `await blob.DownloadStreamingAsync();` | Streams the file content from Azure |
> | `return File(response.Value.Content, response.Value.ContentType, fileName);` | Sends the file to the browser. The `fileName` parameter triggers a "Save As" download |
> | **`Delete()` action** | |
> | `await container.DeleteBlobAsync(fileName);` | Deletes the specified blob from Azure |
> | `TempData["Message"] = $"Deleted '{fileName}' successfully.";` | Shows a confirmation message |
> | `return RedirectToAction("Index");` | Refreshes the gallery so the deleted image no longer appears |

## PART 5: Troubleshooting

| What You See | Why It Happened | How to Fix |
|---|---|---|
| `403 Forbidden` error | Access key is wrong, expired, or connection string is malformed | Go to Azure Portal → Storage Account → **Security + networking** → **Access keys** → click **Regenerate** on key1 → copy the new connection string → open `appsettings.json` → replace the old string → save → rerun |
| `FormatException` when app starts | Connection string has extra spaces, line breaks, or missing characters | Open `appsettings.json` → verify the string starts with `DefaultEndpointsProtocol=https;` and is all on one line inside the quotes with no extra whitespace |
| Build fails with namespace errors | You may have created the project with **F#** instead of **C#** | Delete the project and recreate it, making sure to select the **C#** version of the MVC template (Step 2.3) |
| `NullReferenceException` on startup | Connection string value is `null` | Verify the key `"AzureBlobStorage"` in `appsettings.json` exactly matches what you used in the code, and the value is not empty |
| Images don't display but upload works | SAS URL generation failed | Check that your system clock is correct. SAS URLs are time-sensitive. Also verify the Storage Account allows Blob access |
| Delete confirmation shows wrong filename | Special characters in filename | Avoid special characters in filenames. Stick to letters, numbers, hyphens, underscores, and dots |

```
BlobStorageApp (Solution)
 └── BlobWebRole (Project — C#, .NET 8.0, ASP.NET Core MVC)
      ├── Controllers/
      │    └── BlobController.cs          ← 4 actions: Index, Upload, Download, Delete
      ├── Models/
      │    ├── BlobModel.cs               ← Data model (FileName, FileUrl, ContentType)
      │    └── ErrorViewModel.cs          ← Default template file (not modified)
      ├── Views/
      │    ├── Home/
      │    │    ├── Index.cshtml           ← Main page: gallery + upload form + download + delete
      │    │    └── Privacy.cshtml         ← Default template file (not modified)
      │    └── Shared/
      │         ├── _Layout.cshtml         ← Default layout (not used by Index due to Layout = null)
      │         ├── _ValidationScriptsPartial.cshtml
      │         └── Error.cshtml
      ├── Properties/
      │    └── launchSettings.json
      ├── wwwroot/                         ← Static files (CSS, JS, images)
      ├── appsettings.json                 ← Connection string stored here
      ├── BlobWebRole.csproj               ← Project file (lists NuGet packages)
      └── Program.cs                       ← App entry point (auto-generated, no changes needed)
```
