# Nisha Azure Lab Experiments

Hands-on notes and experiments for learning **Microsoft Azure**. Each lab is a complete, step-by-step guide covering the portal, CLI/PowerShell commands, configuration, and common errors with fixes.

## Experiments

1. [[1. Azure Student Account|Azure Student Account]] — create a free Azure for Students account with $100 credit, from sign-up to portal access, with all validation rules and error handling.
2. [[2. Blob Storage|Blob Storage]] — store and serve unstructured data (images, files, backups) with Azure Blob Storage.
3. [[3. Table Storage|Table Storage]] — semi-structured NoSQL key/attribute storage for fast, cost-effective datasets.
4. [[4. Queue Storage|Queue Storage]] — reliable message queuing to decouple app components and scale workloads.
5. [[5. File Storage|File Storage]] — managed SMB file shares in the cloud.
6. [[6. Azure VM|Azure Virtual Machines]] — create and manage Windows/Linux VMs, remote desktop access, and run projects in the cloud.
9. [[9. Service Bus Relayed Messaging|Service Bus Relayed Messaging]] — connect two programs across firewalls with Azure Relay without opening inbound ports.
10. [[10. Service Bus Queue|Service Bus Queue]] — brokered messaging with queues so sender and receiver need not run at the same time.
11. [[11. Service Bus Topics|Service Bus Topics]] — publish/subscribe with topics and subscriptions so one message reaches many receivers.

## Getting Started

If you are new to Azure, start with [[1. Azure Student Account|Azure Student Account]] — it walks you through creating the free student subscription that you will use in every other lab.
