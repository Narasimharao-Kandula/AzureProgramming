
# Experiment 4: Azure Queue Storage with Background Worker

## Complete Beginner-Friendly Step-by-Step Guide

---

## WHAT YOU ARE BUILDING

You are building a simple **email sending system** with two parts:

```
[User fills form] → [Web App sends message to Azure Queue] → [Worker reads message] → [Email sent via Gmail]
```

- **Part A — WebRoleClient**: A web page with a form (Email, Subject, Body). When you click "Insert to Queue," the data goes into an Azure Queue.
- **Part B — WorkerRoleService**: A background program that constantly checks the queue, picks up messages, and sends real emails using Gmail SMTP.

## PART 1 — CREATE AZURE RESOURCES

### Step 1.1: Create a Storage Account

1. Open your browser and go to **https://portal.azure.com**. Sign in.
2. At the top of the page, click **"Create a resource"** (or click the **+** icon in the left menu).
3. In the search box, type **"Storage account"** and press Enter.
4. Click **"Storage account"** (published by Microsoft), then click **"Create"**.
5. Fill in the form:

| Field | What to Enter |
|---|---|
| **Subscription** | Select your subscription |
| **Resource group** | Click **"Create new"** → type `LabGroup` → OK |
| **Storage account name** | Type a globally unique name, e.g., `cplabstorage494` (lowercase, no spaces, 3–24 characters) |
| **Region** | Choose the closest region to you |
| **Redundancy** | Select **"Locally-redundant storage (LRS)"** (cheapest option) |

6. Click **"Review + Create"**.
7. Click **"Create"**. Wait for the deployment to finish (1–2 minutes).
8. Click **"Go to resource"**.

### Step 1.2: Copy the Connection String

1. In your storage account's left menu, click **"Security + networking"** → **"Access keys"**.
2. You will see **Key1** and **Key2**. Under **Key1**, click **"Show"** next to the **Connection string** field.
3. Click the **copy icon** next to the connection string.
4. **Paste it into a text file temporarily.** You will need it in two places later.

Your connection string will look something like:
```
DefaultEndpointsProtocol=https;AccountName=cplabstorage494;AccountKey=AbCdEfG...==;EndpointSuffix=core.windows.net
```

### Step 1.3: Create a Gmail App Password

> **Why?** Gmail does not allow regular passwords for apps. You need a special 16-character "App Password."

1. Go to **https://myaccount.google.com/security** and sign in to your Gmail.
2. Under "How you sign in to Google," make sure **2-Step Verification** is **On**. If not, click it and follow the steps to enable it.
3. Once 2-Step Verification is on, go back to the Security page.
4. Search for **"App Passwords"** (or go to **https://myaccount.google.com/apppasswords**).
5. In the "App name" field, type: `AzureQueueApp`
6. Click **"Create"**.
7. Google will show a **16-character password** like `abcd efgh ijkl mnop`.
8. **Copy it** (remove the spaces, so it becomes `abcdefghijklmnop`).
9. **Paste it into the same text file** where you saved the connection string.

### Step 3.4: Create the Controller

**Location:** `WebRoleClient/Controllers/HomeController.cs`

**Delete everything** in this file and replace it with:

```csharp
using System.Text.Json;
using Azure.Storage.Queues;
using Microsoft.AspNetCore.Mvc;
using WebRoleClient.Models;

namespace WebRoleClient.Controllers
{
    public class HomeController : Controller
    {
        private readonly QueueClient _queueClient;

        public HomeController(QueueClient queueClient) => _queueClient = queueClient;

        public IActionResult Index() => View();

        [HttpPost]
        public async Task<IActionResult> InsertToQueue(EmailModel model)
        {
            await _queueClient.CreateIfNotExistsAsync();

            string json = JsonSerializer.Serialize(model);
            string base64 = Convert.ToBase64String(System.Text.Encoding.UTF8.GetBytes(json));

            await _queueClient.SendMessageAsync(base64);
            ViewBag.Status = "Queued successfully!";
            return View("Index");
        }
    }
}
```

**What this does:**
- **Constructor**: Receives the `QueueClient` via dependency injection (registered in `Program.cs`).
- **Index (GET)**: Returns the form view.
- **InsertToQueue (POST)**: When the form is submitted:
  1. Creates the queue if it does not exist yet.
  2. Serializes the `EmailModel` to a JSON string.
  3. Encodes that JSON to Base64 (the format Azure Queue messages use).
  4. Sends the message to the queue.
  5. Sets a success message and returns the view.

### Step 4.2: Implement the Worker

**Location:** `WorkerRoleService/Worker.cs`

**Delete everything** in this file and replace it with:

```csharp
using System.Net;
using System.Net.Mail;
using System.Text;
using System.Text.Json;
using Azure.Storage.Queues;
using Azure.Storage.Queues.Models;
using Microsoft.Extensions.Hosting;
using Microsoft.Extensions.Logging;

namespace WorkerRoleService;

public class EmailModel
{
    public string EmailId { get; set; }
    public string Subject { get; set; }
    public string Body { get; set; }
}

public class Worker : BackgroundService
{
    private readonly ILogger<Worker> _logger;
    private readonly QueueClient _queue;
    private const string Gmail = "YOUR_GMAIL@gmail.com";
    private const string AppPass = "YOUR_APP_PASSWORD";

    public Worker(ILogger<Worker> logger, IConfiguration config)
    {
        _logger = logger;
        string conn = config.GetConnectionString("queuecs")!;
        _queue = new QueueClient(conn, "mailqueue");
    }

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        _logger.LogInformation("[Worker] Background processing engine active.");
        await _queue.CreateIfNotExistsAsync(cancellationToken: stoppingToken);

        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                QueueMessage[] messages = await _queue.ReceiveMessagesAsync(
                    maxMessages: 1,
                    visibilityTimeout: TimeSpan.FromMinutes(2),
                    cancellationToken: stoppingToken);

                if (messages.Length == 0)
                {
                    await Task.Delay(5000, stoppingToken);
                    continue;
                }

                QueueMessage msg = messages[0];
                EmailModel? emailData;

                try
                {
                    string json = Encoding.UTF8.GetString(Convert.FromBase64String(msg.Body.ToString()));
                    emailData = JsonSerializer.Deserialize<EmailModel>(json);
                }
                catch
                {
                    _logger.LogWarning("[Worker] Bad message format. Deleting poison message.");
                    await _queue.DeleteMessageAsync(msg.MessageId, msg.PopReceipt, stoppingToken);
                    continue;
                }

                if (emailData is not null)
                {
                    _logger.LogInformation("[Worker] Sending email to: {Email}", emailData.EmailId);

                    try
                    {
                        using var smtp = new SmtpClient("smtp.gmail.com", 465)
                        {
                            EnableSsl = true,
                            Credentials = new NetworkCredential(Gmail, AppPass)
                        };
                        using var mail = new MailMessage(Gmail, emailData.EmailId, emailData.Subject, emailData.Body);
                        await smtp.SendMailAsync(mail);

                        _logger.LogInformation("[Worker] Email sent successfully!");
                        await _queue.DeleteMessageAsync(msg.MessageId, msg.PopReceipt, stoppingToken);
                    }
                    catch (Exception smtpEx)
                    {
                        _logger.LogError("[Worker] SMTP Error: {Error}", smtpEx.Message);
                        await Task.Delay(10000, stoppingToken);
                    }
                }
            }
            catch (Exception ex)
            {
                _logger.LogError("[Worker] Loop Error: {Error}", ex.Message);
                await Task.Delay(5000, stoppingToken);
            }
        }
    }
}
```

**Before saving, you MUST replace two things:**

| Placeholder | Replace With |
|---|---|
| `YOUR_GMAIL@gmail.com` | Your actual Gmail address (appears 3 times) |
| `YOUR_APP_PASSWORD` | The 16-character App Password from Step 1.3 (no spaces) |

**What this does, step by step:**
1. On startup, creates the queue if it does not exist.
2. Enters a **forever loop** that:
   - Requests 1 message from the queue (with a 2-minute visibility timeout).
   - If no message is found, waits 5 seconds and tries again.
   - If a message is found, Base64-decodes it → JSON → `EmailModel`.
   - If decoding fails (malformed message), it deletes the "poison" message and continues.
   - If decoding succeeds, it sends an email using Gmail SMTP on port 465 with SSL.
   - Only **after** the email is sent successfully, the message is deleted from the queue.
   - If SMTP fails, it logs the error and waits 10 seconds before retrying (the message becomes visible again in the queue).

## PART 7 — TROUBLESHOOTING

| Symptom | Cause | Fix |
|---|---|---|
| Worker fails to start or crashes immediately | Missing runtime config in `.csproj` | Make sure you added `GenerateRuntimeConfigurationFiles` and `CopyLocalLockFileAssemblies` in Step 2.6 |
| "Queued successfully" shows but no email arrives | Wrong Gmail credentials in `Worker.cs` | Verify your Gmail address is correct and App Password has no spaces |
| Worker logs "SMTP Error" | 2-Step Verification not enabled, or App Password invalid | Go to Google Account → Security → ensure 2FA is on → generate a new App Password |
| Worker logs "Bad message format" | Queue has old malformed messages | This is expected — the worker auto-deletes them. Try submitting the form again. |
| SMTP timeout or connection refused | Port 465 blocked by firewall | Change the SMTP port to `587` in `Worker.cs` and keep `EnableSsl = true` |
| "Queue not found" or connection error | Wrong connection string in `appsettings.json` | Re-copy the connection string from Azure Portal → Storage Account → Access keys |
