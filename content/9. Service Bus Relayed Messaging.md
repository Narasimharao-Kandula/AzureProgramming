## Why This Experiment

Two programs on different computers need to talk. Normally one must **open a network port** so the other can connect. But firewalls, routers, and company security policies block that.

**Azure Relay** solves this with one trick:

> Both computers **dial out** to Microsoft Azure instead of into each other. Azure holds both live connections and joins them together. Nobody opens a port.

This pattern — called **relayed messaging** — is the backbone of hybrid cloud apps, IoT devices behind home routers, remote-support tools, and chat apps connecting users on different networks.

By doing this experiment you will learn to create an Azure Relay resource, write a C# Service and Client that talk through the cloud, and read real cloud errors confidently.

## What Are We Building

| Piece | Name | Role |
|---|---|---|
| Cloud middle-man | **RelayEXP7** (Azure Relay) | Introduces the two programs |
| Server program | **Service** | Waits quietly, prints every message received |
| Client program | **Client** | Sends whatever the user types |

**What you will see:** you type a message in the **Client** window → it appears in the **Service** window → the Service sends a reply back → the reply appears in the **Client** window. Two black console windows chatting through the cloud.

## How It Works

### Real-time example — the railway station

Imagine two friends, **Anu** and **Bala**, who want to meet:
- Anu lives in Town A behind a **locked gate** (firewall)
- Bala lives in Town B behind a **locked gate** (firewall)
- Neither is allowed to open their gate

**Solution:** they both walk OUT to the big **Central Railway Station** and meet on **Platform 5**.

```
  Anu's house           Central Station            Bala's house
  (locked gate)         (open to everyone)         (locked gate)
       │                                                │
       │ walks OUT ──────►  Platform 5  ◄──────── walks OUT
       │                    (ChatHub)                    │
       └───────────── they meet right here ─────────────┘
```

| Railway station | In our code |
|---|---|
| Anu | **Service** (waits at the platform) |
| Bala | **Client** (arrives and starts talking) |
| Central Railway Station | **Azure Relay** (namespace `RelayEXP7`) |
| Platform 5 | **ChatHub** (the meeting point) |
| Walking out of the gate | Outbound connection (always allowed) |
| Station master joining them | Azure joins the two live connections |

### The technical picture

```
      ┌──────────┐                                  ┌──────────┐
      │  Service │                                  │  Client  │
      └────┬─────┘                                  └────┬─────┘
           │ ① dials OUT "I am waiting in ChatHub"       │
           │                                             │ ③ dials OUT
           │                                             │   "Connect me to ChatHub"
           ▼                                             ▼
  ╔═══════════════════════════════════════════════════════════════╗
  ║              AZURE RELAY  ·  namespace: RelayEXP7            ║
  ║          ② sees both lines live and joins them               ║
  ╚═══════════════════════════════════════════════════════════════╝
           │                                             │
           └──────── ④ two-way chat flows from here ─────┘
```

### Second by second

| Time | What happens |
|---|---|
| T+0s | **Service** starts, dials out to Azure, waits on `ChatHub` |
| T+5s | **Client** starts, dials out to Azure, asks for `ChatHub` |
| T+6s | Azure joins the two live connections |
| T+7s | Client sends `"Hello"` → Service prints it and replies |
| T+8s | Client prints the reply |

> 💡 **The one idea to remember:** neither computer opened an inbound port. Both dialled out. Azure did the joining. That is relayed messaging.

## Step-by-Step Implementation

### Create the Azure Relay

1. Open **`portal.azure.com`** → sign in.
2. Click **+ Create a resource** → search **`Relay`** → click **Create**.
3. Fill in: **Subscription** (yours) · **Resource group** → *Create new* → `RelayEXP7-RG` · **Name** → `RelayEXP7` · **Region** → closest to you.
4. Click **Review + create** → **Create** → wait a minute → **Go to resource**.
5. Left menu → **Hybrid connections** → **+ Hybrid Connection** → Name: `ChatHub` → **Create**.
6. Left menu → **Shared access policies** → click **`RootManageSharedAccessKey`** → copy the **Primary Key** (the long string ending in `=`) into Notepad.

> ✅ **Checkpoint:** Notepad has the Primary Key. Azure is ready.

---

### Build the Service

**Step 1 — Create the project**

Open **Visual Studio** → **Create a new project** → search **`Console App`** → pick **C# · Console** → **Next**.

| Field | Value |
|---|---|
| Project name | `Service` |
| Solution name | `RelayEXP7` |
| Framework | **.NET Framework 4.8** |

Click **Create**.

**Step 2 — Install the Azure Relay SDK**

Right-click the **`Service`** project in Solution Explorer → **Manage NuGet Packages** → **Browse** tab → search **`Microsoft.Azure.Relay`** → **Install**.

> ⚠️ Do **not** install `WindowsAzure.ServiceBus` — that is the old legacy package. We use only `Microsoft.Azure.Relay`.
> ✅ Expand **Dependencies → Packages** and confirm `Microsoft.Azure.Relay` is listed.

**Step 3 — Paste this code into `Program.cs`**

Open `Program.cs` → **Ctrl+A → Delete** → paste this entire code:

```csharp
using System;
using System.IO;
using System.Text;
using System.Threading.Tasks;
using Microsoft.Azure.Relay;

namespace Service
{
    class Program
    {
        // EDIT THESE THREE VALUES
        const string NamespaceName        = "RelayEXP7";
        const string HybridConnectionName = "ChatHub";
        const string SharedAccessKey      = "PASTE_KEY_HERE";

        static void Main()
        {
            try { RunAsync().GetAwaiter().GetResult(); }
            catch (Exception ex) { Console.WriteLine("[ERROR] " + ex.Message); }
            finally { Console.WriteLine("Press ENTER to close..."); Console.ReadLine(); }
        }

        static async Task RunAsync()
        {
            // WHERE to meet and WHO is allowed in
            Uri uri = new Uri("sb://" + NamespaceName
                       + ".servicebus.windows.net/" + HybridConnectionName);
            var token = TokenProvider
                .CreateSharedAccessSignatureTokenProvider(
                    "RootManageSharedAccessKey", SharedAccessKey);

            // Open the door and wait for a client
            var listener = new HybridConnectionListener(uri, token);
            await listener.OpenAsync();
            Console.WriteLine("[SERVICE] Listening on " + uri);

            var connection = await listener.AcceptConnectionAsync();
            Console.WriteLine("[SERVICE] Client connected!");

            // Two pipes: read from client, write back to client
            var reader = new StreamReader(connection, Encoding.UTF8);
            var writer = new StreamWriter(connection, Encoding.UTF8)
                { AutoFlush = true };

            // Chat loop
            string msg;
            while ((msg = await reader.ReadLineAsync()) != null)
            {
                Console.WriteLine("[SERVICE] Received : " + msg);
                string reply = "I got '" + msg + "' at "
                             + DateTime.Now.ToString("HH:mm:ss");
                await writer.WriteLineAsync(reply);
            }

            await listener.CloseAsync();
        }
    }
}
```

**Step 4 — Fill in your key**

Find the line `const string SharedAccessKey = "PASTE_KEY_HERE";` and replace `PASTE_KEY_HERE` with the Primary Key from Notepad. Keep the quotes.

**Step 5 — Save and build**

Press **Ctrl+S** to save → **Ctrl+Shift+B** to build. The Output window should show `Build succeeded`.

> ✅ **Checkpoint:** Service builds with zero errors.

### Build the Client

**Step 1 — Create the project**

**File → New → Project** → **Console App (C#)** → **Next**.

| Field | Value |
|---|---|
| Project name | `Client` |
| Solution | **Add to solution** `RelayEXP7` |
| Framework | **.NET Framework 4.8** |

Click **Create**.

**Step 2 — Install the Azure Relay SDK**

Same as before: right-click **`Client`** project → **Manage NuGet Packages** → **Browse** → search **`Microsoft.Azure.Relay`** → **Install**.

**Step 3 — Paste this code into `Program.cs`**

Open `Program.cs` → **Ctrl+A → Delete** → paste this entire code:

```csharp
using System;
using System.IO;
using System.Text;
using System.Threading.Tasks;
using Microsoft.Azure.Relay;

namespace Client
{
    class Program
    {
        // EDIT THESE THREE VALUES (same as Service)
        const string NamespaceName        = "RelayEXP7";
        const string HybridConnectionName = "ChatHub";
        const string SharedAccessKey      = "PASTE_KEY_HERE";

        static void Main()
        {
            try { RunAsync().GetAwaiter().GetResult(); }
            catch (Exception ex) { Console.WriteLine("[ERROR] " + ex.Message); }
            finally { Console.WriteLine("Press ENTER to close..."); Console.ReadLine(); }
        }

        static async Task RunAsync()
        {
            // SAME address and key as the Service
            Uri uri = new Uri("sb://" + NamespaceName
                       + ".servicebus.windows.net/" + HybridConnectionName);
            var token = TokenProvider
                .CreateSharedAccessSignatureTokenProvider(
                    "RootManageSharedAccessKey", SharedAccessKey);

            // Dial out and connect
            var client = new HybridConnectionClient(uri, token);
            var connection = await client.CreateConnectionAsync();
            Console.WriteLine("[CLIENT] Connected to Service through Azure Relay!");

            var reader = new StreamReader(connection, Encoding.UTF8);
            var writer = new StreamWriter(connection, Encoding.UTF8)
                { AutoFlush = true };

            // Background: listen for replies
            Task.Run(async () =>
            {
                string reply;
                while ((reply = await reader.ReadLineAsync()) != null)
                    Console.WriteLine("[SERVICE] replied : " + reply);
            });

            // Foreground: send what the user types
            Console.WriteLine("[CLIENT] Type a message (or 'exit' to quit):");
            string input;
            while ((input = Console.ReadLine()) != null
                   && input.ToLower() != "exit")
                await writer.WriteLineAsync(input);

            connection.Dispose();
            await Task.Delay(500);
        }
    }
}
```

**Step 4 — Fill in your key**

Same as before: replace `PASTE_KEY_HERE` with the **same** Primary Key from Notepad.

**Step 5 — Save and build**

**Ctrl+S** → **Ctrl+Shift+B** → `Build succeeded`.

> ✅ **Checkpoint:** Both projects build with zero errors.

### Run and Test

> ⚠️ **Start the Service FIRST.** Relay is a meeting point, not a mailbox. If nobody is waiting, the Client has nobody to meet.

1. Right-click **`Service`** → **Debug → Start New Instance**.
   Wait for:
   ```
   [SERVICE] Listening on sb://RelayEXP7.servicebus.windows.net/ChatHub
   ```
   **Leave this window open.**

2. Right-click **`Client`** → **Debug → Start New Instance**.
   Wait for:
   ```
   [CLIENT] Connected to Service through Azure Relay!
   ```
   The Service window now also shows: `[SERVICE] Client connected!`

3. Type `Hello` in the Client window → **Enter**. Watch it appear in both windows.

4. Type `exit` in the Client to close → press **Enter** in the Service to close.

> ✅ **Checkpoint:** messages appeared in both windows — relayed messaging is working.

## Troubleshooting

### While building

| You see | Why | Fix |
|---|---|---|
| `'Relay' does not exist in 'Microsoft'` | NuGet not installed | Install `Microsoft.Azure.Relay` on **each** project |
| `Target framework 'net48' not found` | Targeting pack missing | VS Installer → Modify → tick **.NET Framework 4.8 targeting pack** |
| `HybridConnectionListener` / `RelayedConnection` not found | Missing `using` | Add `using Microsoft.Azure.Relay;` at the top |

### While running

| You see | When | Why | Fix |
|---|---|---|---|
| `Unauthorized` / `401` | Service start or Client connect | Wrong or different key | Re-copy the key; both projects must use the **same** key |
| `TimeoutException` / `RelayNotReady` | Client connecting | Service is not running | Start **Service first**, then Client |
| `EndpointNotFound` / `404` | Client connecting | `ChatHub` does not exist | Create `ChatHub` in Azure portal |
| `NamespaceNotFound` | Service start | Namespace name typo | Must be exactly `RelayEXP7` |
| `SocketException` / `Unable to connect` | Either | No internet, or firewall blocks `*.servicebus.windows.net` | Try a different network |
| Client connects but no reply shown | Chat loop | `AutoFlush` missing on `StreamWriter` | Check the code — `{ AutoFlush = true }` must be there |

### Quick sanity check before asking for help

- [ ] Both projects target **.NET Framework 4.8**
- [ ] Both have **`Microsoft.Azure.Relay`** in Dependencies → Packages
- [ ] Both use the **same** namespace, hybrid connection name, and key
- [ ] **Service** was started **before** Client
