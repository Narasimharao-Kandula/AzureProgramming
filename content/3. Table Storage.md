# Azure Table Storage — Complete Beginner's Step-by-Step Guide

> Based on: *Cloud Service with WebRole Demonstrating Azure Table Storage*
> Compatible with: **Visual Studio Community 2022 / 2026 / 2026 Insiders**

---

## What You Will Build

A web application (called a **WebRole**) that stores customer records in the cloud using **Azure Table Storage**. You will be able to:

- **Create** new customer records
- **Read** (view) all stored records
- **Update** existing records
- **Delete** records

This is known as **CRUD** functionality. Each record gets an automatically incrementing ID (1, 2, 3...).

## Part 1: Create Azure Storage Account (Step-by-Step)

This is where your data will live in the cloud.

### Step 1.1 — Open Azure Portal
- Go to [https://portal.azure.com](https://portal.azure.com)
- Sign in with your Microsoft/Azure credentials.

### Step 1.2 — Create Storage Account
1. On the Azure Portal home page, click **"Create a resource"** (top-left or in the center).
2. In the search bar, type **"Storage Account"**.
3. Click **"Storage Account"** from the results → click **"Create"**.

### Step 1.3 — Fill In the Configuration

| Field | What to Enter | Notes |
|---|---|---|
| **Subscription** | Select your active Azure subscription | Usually shown by default |
| **Resource Group** | Click "Create new" → type `LabExperiments` → OK | A folder to organize your resources |
| **Storage Account Name** | Type a unique name, e.g., `tablestorage2026` | Must be globally unique, lowercase letters and numbers only |
| **Region** | Select the datacenter nearest to you | e.g., "East US", "West Europe" |
| **Performance** | Select **Standard** | Sufficient for this lab |
| **Redundancy** | Select **Locally-redundant storage (LRS)** | Cheapest option; data is replicated within one datacenter |

### Step 1.4 — Create the Resource
1. Click **"Review + Create"** at the bottom.
2. Wait for validation to pass (you'll see a green checkmark).
3. Click **"Create"**.
4. Wait for deployment to finish (usually 1–2 minutes).
5. Click **"Go to resource"**.

### Step 1.5 — Copy Your Connection String
This is a special string of text that lets your application talk to Azure Storage.

1. In your storage account's left menu, go to **"Security + networking"** → **"Access keys"**.
2. Under **key1**, click **"Show"** next to the **Connection string** field.
3. Click the **copy icon** to copy the full connection string.
4. **Paste it somewhere safe** (like Notepad). You will need it in Part 3.

> Your connection string will look something like:
> `DefaultEndpointsProtocol=https;AccountName=tablestorage2026;AccountKey=aBcDeFg...==;EndpointSuffix=core.windows.net`

## Part 3: Write the Application Code

### Step 3.1 — Configure the Connection String

This tells your app how to connect to your Azure Storage Account.

1. In **Solution Explorer**, find and double-click **`appsettings.json`** to open it.
2. **Replace the entire contents** with the following:

```json
{
  "Logging": {
    "LogLevel": {
      "Default": "Information",
      "Microsoft.AspNetCore": "Warning"
    }
  },
  "AllowedHosts": "*",
  "ConnectionStrings": {
    "AzureTableStorage": "PASTE_YOUR_CONNECTION_STRING_HERE"
  }
}
```

3. **Replace** `PASTE_YOUR_CONNECTION_STRING_HERE` with the connection string you copied in Step 1.5.
4. Press **Ctrl+S** to save.

### Step 3.2 — Create the Data Model

The **model** defines the structure of each record stored in Azure Table Storage.

1. In **Solution Explorer**, right-click the **`Models`** folder → **"Add"** → **"Class..."**.
2. Name the file: **`CustomerEntity.cs`**
3. Click **"Add"**.
4. **Replace the entire contents** with:

```csharp
using Azure;
using Azure.Data.Tables;

namespace TableWebRole.Models
{
    public class CustomerEntity : ITableEntity
    {
        public string PartitionKey { get; set; } = default!;
        public string RowKey { get; set; } = default!;
        public DateTimeOffset? Timestamp { get; set; }
        public ETag ETag { get; set; }
        public string Name { get; set; } = default!;
        public string Email { get; set; } = default!;
    }
}
```

**What each property means:**

| Property | Purpose |
|---|---|
| `PartitionKey` | Groups related records (here, it represents the customer "Type") |
| `RowKey` | Unique ID within the partition (here, it will be an auto-incrementing number: 1, 2, 3...) |
| `Timestamp` | Automatically set by Azure |
| `ETag` | Used by Azure for concurrency control |
| `Name` | Customer's name (your custom field) |
| `Email` | Customer's email (your custom field) |

5. Press **Ctrl+S** to save.

### Step 3.4 — Create the Controller

The **controller** handles user requests and contains the CRUD logic.

1. In **Solution Explorer**, open **`Controllers`**.
2. Right-click **`Controllers`** folder → **"Add"** → **"Controller..."**.
3. Select **"MVC Controller - Empty"** → click **"Add"**.
4. Name it: **`TableController.cs`**
5. Click **"Add"**.
6. **Replace the entire contents** with:

```csharp
using Microsoft.AspNetCore.Mvc;
using Azure.Data.Tables;
using TableWebRole.Models;

namespace TableWebRole.Controllers
{
    public class TableController : Controller
    {
        private readonly string _cs;
        public TableController(IConfiguration cfg) => _cs = cfg.GetConnectionString("AzureTableStorage")!;
        private TableClient GetClient() => new(_cs, "customers");

        [HttpGet]
        public async Task<IActionResult> Index()
        {
            var c = GetClient();
            await c.CreateIfNotExistsAsync();
            var list = new List<CustomerEntity>();
            await foreach (var e in c.QueryAsync<CustomerEntity>()) list.Add(e);
            return View("~/Views/Home/Index.cshtml", list.OrderBy(x => int.Parse(x.RowKey)).ToList());
        }

        [HttpPost]
        public async Task<IActionResult> Insert(string customerType, string name, string email)
        {
            var c = GetClient();
            await c.CreateIfNotExistsAsync();
            var rows = new List<CustomerEntity>();
            await foreach (var e in c.QueryAsync<CustomerEntity>(select: new[] { "RowKey" })) rows.Add(e);
            int nextId = rows.Count == 0 ? 1 : rows.Max(x => int.Parse(x.RowKey)) + 1;
            await c.UpsertEntityAsync(new CustomerEntity { PartitionKey = customerType, RowKey = nextId.ToString(), Name = name, Email = email });
            return RedirectToAction("Index");
        }

        [HttpGet]
        public async Task<IActionResult> Edit(string pk, string rk)
        {
            var entity = await GetClient().GetEntityAsync<CustomerEntity>(pk, rk);
            ViewBag.EditEntity = entity.Value;
            return await Index();
        }

        [HttpPost]
        public async Task<IActionResult> Update(string customerType, string customerId, string name, string email)
        {
            await GetClient().UpsertEntityAsync(new CustomerEntity { PartitionKey = customerType, RowKey = customerId, Name = name, Email = email });
            return RedirectToAction("Index");
        }

        [HttpGet]
        public async Task<IActionResult> Delete(string pk, string rk)
        {
            await GetClient().DeleteEntityAsync(pk, rk);
            return RedirectToAction("Index");
        }
    }
}
```

**What each action does:**

| Action | HTTP | Purpose |
|---|---|---|
| `Index` | GET | Reads ALL records from the `customers` table and displays them sorted by ID |
| `Insert` | POST | Creates a new record with an auto-incremented RowKey |
| `Edit` | GET | Fetches a single record by PartitionKey + RowKey and loads it into the edit form |
| `Update` | POST | Saves changes to an existing record |
| `Delete` | GET | Removes a record by its PartitionKey + RowKey |

**How auto-increment works:**
The `Insert` action queries all existing records, finds the highest `RowKey` number, and adds 1. If no records exist, it starts at 1.

7. Press **Ctrl+S** to save.

## Part 4: Run and Verify

### Step 4.1 — Set Startup Project
1. In **Solution Explorer**, right-click **`TableWebRole`** → **"Set as Startup Project"**.

### Step 4.2 — Launch the Application
1. Press **Ctrl+F5** (runs without debugging) or **F5** (runs with debugging).
2. A browser window will open showing the page at `http://localhost:<port>`.

### Step 4.3 — Test CRUD Operations

**Create a record:**
1. In the "Type" field, enter a category (e.g., `Premium`).
2. In the "Name" field, enter a name (e.g., `Alice`).
3. In the "Email" field, enter an email (e.g., `alice@example.com`).
4. Click **"Save"**.
5. The record appears in the table below with **ID: 1**.

**Create more records:**
- Repeat with different data. IDs will auto-increment: 1, 2, 3...

**Edit a record:**
1. Click **"Edit"** next to any record.
2. The form switches to "Update Entry" mode and pre-fills the data.
3. Change the Name or Email → click **"Save"**.

**Delete a record:**
1. Click **"Delete"** next to any record.
2. Confirm the deletion in the popup dialog.

### Step 4.4 — Verify in Azure Portal
1. Go back to [Azure Portal](https://portal.azure.com).
2. Open your **Storage Account** → left menu → **"Storage browser"** → **"Tables"**.
3. Click on the **`customers`** table.
4. You should see all the records you created, confirming data persists in the cloud.

## Part 5: Troubleshooting

| Problem | What Went Wrong | How to Fix |
|---|---|---|
| **403 Forbidden** error | Your access key may be invalid or rotated | Go to Azure Portal → Storage Account → Access Keys → click **"Regenerate"** for key1 → copy the new connection string → paste it into `appsettings.json` → restart the app |
| **Sorting crashes** when loading the page | The `RowKey` is being treated as text instead of a number | This is already handled in the code above using `int.Parse(x.RowKey)` in the `OrderBy` clause. If you modified the code, ensure this line is present: `list.OrderBy(x => int.Parse(x.RowKey))` |
