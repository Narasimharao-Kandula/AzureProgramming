# PART B — Install & Configure Microsoft SQL Server 2022
## Complete Beginner-Friendly Professional Lab Manual

**All steps in this part run INSIDE the Azure VM via RDP (Desktop 2).**

**Time Required:** 30–45 minutes

**What you will build:** A working SQL Server database that stores student records, accessible from the J2EE web application we build in Part D.

**Before starting, confirm:**
```
✅ Part A is complete
✅ You are connected to the Azure VM via RDP (Desktop 2)
✅ VM desktop is visible (Windows Server 2022)
✅ Internet works inside the VM (tested with ping google.com)
✅ IE Enhanced Security is OFF (Step A6)
✅ Windows Firewall rules added (Step A8)
✅ Notepad on Desktop 1 has all credentials so far
```

### Possible Error B1.1: Page doesn't load or shows "Can't reach this page"

```
Why:    Internet not working inside the VM.

Fix:    Step 1: Test internet
            → Open a new Edge tab: Ctrl + T
            → Navigate to: https://google.com
            → If Google loads: The SQL Server page might be temporarily down
               → Wait 2 minutes → Try again
            → If Google doesn't load: No internet inside VM
               → Go back to Part A Step A9 and fix internet first

        Step 2: If internet works but the specific URL fails
            → Try this alternative URL:
               https://www.microsoft.com/en-us/evalcenter/evaluate-sql-server-2022
            → Select "Developer" edition
            → Download the installer
```

### Possible Error B1.2: Download is blocked or doesn't start

```
Why:    IE Enhanced Security is still ON (blocking downloads).

Fix:    → Go back to Part A Step A6
        → Make sure IE Enhanced Security is set to OFF
        → Close Edge completely (right-click Edge in taskbar → Close all windows)
        → Re-open Edge
        → Try downloading again
```

### Possible Error B1.3: "Windows Defender SmartScreen prevented the download"

```
Why:    Edge SmartScreen flagged the download.

Fix:    → Look for a banner at the TOP of Edge:
           "Microsoft Defender SmartScreen blocked this download"
        → Click the three dots (...) on the banner
        → Click: "Keep" or "Download anyway"
        → Or: Click "View downloads" → Right-click the blocked file → "Keep"

        If that doesn't work:
        → Edge → Settings (three dots → Settings)
        → Privacy, search, and services
        → Scroll to "Security"
        → Turn OFF "Microsoft Defender SmartScreen"
        → Try downloading again
        → Turn SmartScreen back ON after download
```

### Possible Error B1.4: Download starts but fails at 99% or gets corrupted

```
Why:    Unstable internet connection.

Fix:    → Click the failed download → Click "Retry"
        → If it fails again:
           → Close Edge
           → Re-open Edge
           → Navigate to the download page again
           → Try downloading once more
        → If it keeps failing:
           → The VM may have a slow connection
           → Wait 5 minutes and try during off-peak hours
```

### Verify Download Complete

### Select Authentication Mode

```
Select: ◉ Mixed Mode (SQL Server authentication and Windows authentication)
```

**Why Mixed Mode?**
```
Windows Authentication: Only Windows users can connect.
    → Our Java application (JDBC) CANNOT use this.
    
Mixed Mode: Both Windows users AND SQL Server accounts (like "sa") can connect.
    → Our Java application CAN connect using the "sa" account.
    → This is REQUIRED for the experiment.
```

### Set SA Password ⭐ WRITE THIS DOWN IMMEDIATELY

**SA** = System Administrator. This is the "root" password for SQL Server.

```
Enter password:      P@ssw0rd123!
Confirm password:    P@ssw0rd123!
```

**Password requirements:**
```
✅ At least 8 characters
✅ At least 3 of these 4 categories:
   → Uppercase letters (A-Z)
   → Lowercase letters (a-z)
   → Digits (0-9)
   → Special characters (!@#$%^&*)
❌ Cannot contain the computer name "VM-J2EE-SQL"
❌ Cannot be a commonly used password (like "password" alone)
```

**Recommended passwords (pick one):**
```
P@ssw0rd123!
Sql$erver2022#
Exp6@Database!
Student#DB2025
```

**IMMEDIATELY after typing:**

```
Switch to Desktop 1 (Win + Ctrl + ←)
Open Notepad
Write the SA password:

SQL Server SA:      sa
SQL Server Pass:    P@ssw0rd123!
SQL Port:           1433
Database:           StudentDB

Switch back to Desktop 2 (Win + Ctrl + →)
```

### Possible Error B3.8: "Password does not meet Windows policy requirements"

