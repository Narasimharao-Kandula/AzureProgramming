**Read this entire section once before starting. Then follow step by step.**

**What you will build:** A Windows Server virtual machine running in Microsoft's cloud, accessible from your laptop via Remote Desktop.

**What you need before starting:**
```
✅ Azure subscription (free or paid)
✅ Laptop connected to internet
✅ Desktop 1 — this guide open
✅ Desktop 2 — available for Azure Portal and RDP

✅ At least 6 GB RAM available on your laptop
```

### Possible Error A9.1: "Ping request could not find host google.com"

```
Why:    DNS not configured (rare on Azure VMs).

Fix:    → Try: ping 8.8.8.8
        → If that works: DNS issue only
           → Run: netsh interface ip set dns "Ethernet" static 8.8.8.8
           → Try: ping google.com again
        
        → If ping 8.8.8.8 also fails: No internet at all
           → Azure Portal → VM → Networking
           → Verify outbound rules exist (should be default)
           → Restart the VM: Azure Portal → VM → Restart
           → Reconnect RDP → Try again
```

### Possible Error A9.2: "General failure" or "Destination host unreachable"

```
Why:    VM networking misconfigured.

Fix:    → Azure Portal → VM → Networking
        → Verify the Network Interface exists
        → Verify the Public IP is associated
        → Verify NSG outbound rules allow internet traffic
        
        → Quick fix: Restart the VM
           Azure Portal → VM → Stop → Wait 1 min → Start
           → Reconnect RDP → Try again
```
