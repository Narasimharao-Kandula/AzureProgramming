# Experiment 1: Free Azure Student Account Creation — Complete Step-by-Step Guide

Below is a comprehensive, field-by-field walkthrough for creating an **Azure for Students** free account. Each step includes the fields you will see, the values you should enter, possible errors at that step, and how to handle them.

---

## Pre-Flight: Understand What You're Getting

Before starting, know what the Azure for Students offer provides (citation:3)(citation:4)(citation:5):

| Feature | Details |
|---|---|
| Credit | $100 Azure credit |
| Duration | 12 months (renewable while you remain a student) |
| Credit Card Required | No — student offer does not require a card |
| Verification | Via your educational institution's `.edu` email |
| Includes | Access to 25+ always-free services, plus select free-for-12-months services |

---

## STEP 1: Open the Azure for Students Sign-Up Page

**Action:** Navigate to the URL below in your browser:

```
https://azure.microsoft.com/en-us/free/students/
```

### What You See on the Page
| Element | Description |
|---|---|
| Header banner | "Azure for Students" with $100 credit offer details |
| **Start Free** button | Primary CTA to begin the sign-up process |
| Eligibility notes | States you must be a verified student, 18+, at an accredited institution |

### 1.1 Click **Start Free**

**Possible Error at Step 1:**

| Error | Cause | Fix |
|---|---|---|
| Page does not load / 404 | URL typed incorrectly, regional restriction, or browser blocking | Double-check the URL. Try a different browser or network. Clear cache and cookies. |
| "This offer is not available in your country/region" | Azure for Students is not offered in all regions | Check the [Azure global infrastructure page](https://azure.microsoft.com/en-us/global-infrastructure/) for supported regions. Use a valid region during sign-up. |

---

## STEP 2: Sign In or Create a Microsoft Account

After clicking **Start Free**, you are redirected to the Microsoft sign-in page.

### What You See

| Field / Element | Description |
|---|---|
| **Email or phone** input field | Text field at the center of the page |
| **Next** button | Proceeds to password entry |
| **Create one!** link | Below the sign-in fields; lets you create a new Microsoft account |

### 2.1 — If You Already Have a Microsoft Account

Enter your existing Microsoft account email and click **Next**.

| Field | Value to Enter |
|---|---|
| Email or phone | Your existing `@outlook.com`, `@hotmail.com`, or organizational email |

Then enter your password on the next screen.

### 2.2 — If You Do NOT Have a Microsoft Account (Create One)

Click **Create one!** and fill in the following:

| Field | Value to Enter | Validation Rules |
|---|---|---|
| New email | A valid email you have access to (e.g., `yourname@gmail.com`) | Must be a valid email format |
| Password | A strong password (8+ characters, mix of upper/lowercase, numbers, symbols) | Must meet Microsoft's complexity requirements |
| Country/Region | Select your country from dropdown | Must match your actual location |
| Birthdate | Your real date of birth (MM/DD/YYYY) | You must be 18+ to create an Azure account (citation:4) |

After entering details, Microsoft sends a **verification code** to the email you provided.

| Field | Value to Enter |
|---|---|
| Verification code | The code received in your email inbox |

### Possible Errors at Step 2

| Error | Cause | Fix |
|---|---|---|
| "That Microsoft account doesn't exist" | You entered an email that is not registered as a Microsoft account | Click **Create one!** to register a new account, or check for typos |
| "That account doesn't exist. Do you want to create one?" | Same as above | Follow the account creation flow |
| "Your account or password is incorrect" | Wrong password entered | Use **Forgot password?** to reset |
| "We need to verify your identity" (CAPTCHA) | Microsoft detected unusual activity | Complete the CAPTCHA challenge |
| "You're not old enough" | Birthdate indicates user is under 18 | You must be 18 or older to create an Azure account (citation:4) |
| Verification email not received | Delay, spam filter, or wrong email entered | Check spam/junk folder. Wait 2-3 minutes. Click **Resend code**. |
| "This email is already taken" (during creation) | The email is already linked to a Microsoft account | Use a different email or sign in with the existing account |

### Error Handling — Step 2

- **If under 18:** You cannot proceed. Azure for Students requires you to be 18+ (citation:4). You would need to use a parent/guardian account or wait until you meet the age requirement.
- **If account locked due to too many failed attempts:** Wait 15 minutes, then try again or use the account recovery flow.
- **If verification code expires:** Click **Resend code** to get a new one.

## STEP 3: Identity Verification by Email (Academic Verification)

After signing in, Microsoft verifies that you are a student. This is the critical step unique to the student offer.

### What You See

| Field / Element | Description |
|---|---|
| **Country or Region** dropdown | Select the country where your institution is located |
| **Institution email address** input field | Text field for your academic email |
| **Send verification code** button | Sends a code to your academic email |

### 3.1 Select Your Country

| Field | Value to Enter |
|---|---|
| Country or Region | Select your country from the dropdown (e.g., "United States", "India", "United Kingdom") |

### 3.2 Enter Your Educational Email

| Field | Value to Enter | Validation Rules |
|---|---|---|
| Institution email address | Your official university/college email (e.g., `yourname@university.edu`) | Must be from an accredited educational institution's domain |

> **Important:** Your institution email must match the country you selected (citation:4).

### 3.3 Click **Send Verification Code**

A code is sent to your institution email.

| Field | Value to Enter |
|---|---|
| Verification code | Enter the 6-digit code received at your institution email |

### Possible Errors at Step 3

| Error | Cause | Fix |
|---|---|---|
| "We can't verify your institution email. Please try a different email" | Your email domain is not recognized as an accredited educational institution | Ensure you are using your **official** institution email (not personal). If your school's domain is not recognized, contact Azure support (citation:4). |
| "This offer is not available for your institution" | Your institution may not be in the eligible list | Check with your institution's IT department. Some schools need to register with Microsoft first. |
| "This email has already been used" | Someone else (or you, previously) already used this email for a student account | Use a different email or contact Azure support to recover the old account |
| Verification email not received | Email delivery delay, spam filter, or firewall blocking the email | Check spam/junk folder. Wait 2-3 minutes. Ensure your institution email is active and not full. Try sending the code again. |
| "Unable to verify. Try again later" | Server-side issue with the verification service | Wait a few minutes and retry. If persistent, try a different browser or contact support. |
| "We don't recognize this domain as an education institution" | Your institution's domain is not in the Microsoft Education database (citation:4) | Try an alternative institution email if you have one. Contact Azure support with proof of enrollment. |

### Error Handling — Step 3

- **If your institution email domain is not recognized:**
  1. Confirm the email is from your institution's official domain (not Gmail, Yahoo, etc.).
  2. Contact your institution's IT department to confirm they are registered with Microsoft Education.
  3. If the problem persists, go to [Azure Education Hub](https://azureforeducation.microsoft.com/) and submit a support request (citation:4).
- **If verification code expires:** Click **Send verification code** again.
- **If code is entered incorrectly:** You typically get 3-5 attempts before being locked out temporarily. If locked out, wait 15 minutes and resend.

## STEP 4: Complete Your Profile

After successful email verification, you need to fill in your profile.

### What You See

| Field | Description |
|---|---|
| **First name** | Your legal first name |
| **Last name** | Your legal last name |
| **Phone number** | Your mobile number for additional identity verification |
| **Address line 1** | Street address |
| **City** | Your city |
| **State / Province** | Your state or province (dropdown or text) |
| **Postal / ZIP Code** | Your area postal code |
| **Country / Region** | Pre-filled based on earlier selection |

### 4.1 Fill in Each Field

| Field | Value to Enter | Validation Rules |
|---|---|---|
| First name | Your real first name | Letters only, 1-50 characters |
| Last name | Your real last name | Letters only, 1-50 characters |
| Phone number | Your mobile number with country code (e.g., `+1 555-123-4567`) | Must be a valid phone number; used for SMS verification |
| Address line 1 | Your street address | Required, up to 100 characters |
| City | Your city name | Required |
| State / Province | Select from dropdown or type | Required |
| Postal / ZIP Code | Your area code (e.g., `90210` or `110001`) | Must be valid for the selected country |

### 4.2 Phone Verification

After entering your phone number, you receive a verification code via SMS or call.

| Field | Value to Enter |
|---|---|
| Phone verification method | Choose **Text me** or **Call me** |
| Verification code | Enter the code received |

### Possible Errors at Step 4

| Error | Cause | Fix |
|---|---|---|
| "Invalid phone number" | Number format is wrong, missing country code, or landline entered | Ensure you include the country code (e.g., +1 for US). Use a mobile number, not a landline. |
| "Invalid postal code" | Postal code does not match the selected country/state | Verify your postal code format for your country |
| "Phone number already used" | This number was used to verify another Azure account | Use a different phone number |
| SMS code not received | Carrier issues, number blocked, or wrong number | Wait 2 minutes, click **Resend**, or choose **Call me** instead |
| "This field is required" | One or more mandatory fields left blank | Fill in all required fields (marked with *) |
| "Please enter a valid name" | Numbers or special characters in the name field | Use only letters, hyphens, and spaces |

### Error Handling — Step 4

- **If SMS is not received:** Switch from "Text me" to "Call me" for voice verification.
- **If phone number already in use:** Use a different phone number. Each phone number can only verify a limited number of accounts.
- **If postal code validation fails:** Verify your postal code against the format expected for your country.

## STEP 5: Agreement and Sign Up

### What You See

| Element | Description |
|---|---|
| **Microsoft Azure Agreement** checkbox | Terms and conditions |
| **Privacy Statement** link | Link to Microsoft's privacy policy |
| **Sign up** button | Final button to create the account |

### 5.1 Review and Accept

| Action | Details |
|---|---|
| Read the Microsoft Azure Agreement | Review the terms of service |
| Check the agreement checkbox | "I agree to the subscription agreement, offer details, and privacy statement" |
| Click **Sign up** | Submit your application |

### Possible Errors at Step 5

| Error | Cause | Fix |
|---|---|---|
| "Please accept the agreement" | Checkbox not checked | Check the agreement checkbox before clicking Sign up |
| "We couldn't create your subscription" | Backend issue, duplicate account, or credit limit reached | Wait a few minutes and retry. If persistent, contact Azure support. |
| "Your identity could not be verified" | Mismatch in earlier verification steps | Go back and verify all entered information is consistent and accurate |
| Page times out / spinner never stops | Network connectivity issue or Azure service outage | Check your internet connection. Visit [Azure Status](https://status.azure.com/) to check for outages. Refresh and try again. |

### Error Handling — Step 5

- **If sign-up fails repeatedly:** Clear browser cache, try incognito/private mode, or use a different browser (Chrome, Edge, Firefox).
- **If you get a generic error with no details:** Note the correlation ID (usually shown on the error page) and contact [Azure Support](https://azure.microsoft.com/en-us/support/).
- **If you see "subscription creation failed":** This can happen if Azure detects previous trial abuse from your IP/device. Contact support with your institution details.

## STEP 6: Azure Portal Access — Success Confirmation

After successful sign-up, you are redirected to the Azure Portal.

### What You See

| Element | Description |
|---|---|
| Azure Portal Dashboard | `https://portal.azure.com` |
| Banner at the top | Shows your remaining credit (e.g., "$100 remaining") |
| Subscription name | "Azure for Students" |
| Left navigation panel | Access to all Azure services (Virtual Machines, Storage, App Services, etc.) |

### 6.1 Verify Your Subscription

Navigate to: **Home** → **Subscriptions**

| Field | Expected Value |
|---|---|
| Subscription name | Azure for Students |
| Status | Active |
| Credit remaining | $100.00 |
| Expiration | 12 months from sign-up date |

### 6.2 Verify Available Free Services

Navigate to: **Home** → **Subscriptions** → **Azure for Students** → **Free Services**

You should see services available for free within your student subscription (citation:3)(citation:5).

### Possible Errors at Step 6

| Error | Cause | Fix |
|---|---|---|
| Cannot log in to portal.azure.com | MFA not completed or account not fully activated | Complete MFA setup. Wait 5-10 minutes for propagation. |
| Subscription shows as "Disabled" | Verification incomplete or credit exhausted | Re-verify your identity. If credit is exhausted, wait for the next billing cycle or upgrade. |
| "You don't have any subscriptions" | Sign-up did not complete successfully | Go back to the sign-up page and retry. Contact support if issue persists. |
| MFA prompt appears (citation:1) | Microsoft enforces MFA for all admin portal sign-ins (since October 2024) | Complete the MFA setup by choosing one of: Authenticator app, SMS, or phone call (citation:1). |

### Error Handling — Step 6

- **If MFA is required and you haven't set it up:** Microsoft requires MFA for all Azure portal sign-ins (citation:1). Choose your preferred method:
  - **Microsoft Authenticator app** (recommended)
  - **SMS verification**
  - **Phone call verification**
- **If portal shows no resources/services:** This is normal for a fresh account. You haven't created any resources yet.

## Summary: Complete Flow at a Glance

```
STEP 1: Open Azure for Students page
  └─ 1.1: Click "Start Free"
        └─ Error: Page not loading → Check URL, browser, network

STEP 2: Sign in / Create Microsoft Account
  ├─ 2.1: Existing account → Enter email → Enter password
  │     └─ Error: Wrong password → Reset via "Forgot password"
  └─ 2.2: New account → Enter email, password, birthdate → Verify email
        ├─ Error: Under 18 → Must be 18+
        ├─ Error: Email already taken → Use different email
        └─ Error: Verification not received → Check spam, resend

STEP 3: Academic Email Verification
  ├─ 3.1: Select country
  ├─ 3.2: Enter institution email
  └─ 3.3: Enter verification code
        ├─ Error: Domain not recognized → Contact Azure support
        ├─ Error: Email already used → Use different email
        └─ Error: Code not received → Check spam, resend

STEP 4: Complete Profile
  ├─ 4.1: Fill name, phone, address, postal code
  └─ 4.2: Phone verification (SMS/call)
        ├─ Error: Invalid phone → Use mobile with country code
        └─ Error: SMS not received → Switch to "Call me"

STEP 5: Agreement and Sign Up
  ├─ 5.1: Check agreement checkbox
  └─ 5.2: Click "Sign up"
        ├─ Error: Checkbox not checked → Check it
        └─ Error: Subscription creation failed → Retry, contact support

STEP 6: Access Azure Portal
  ├─ 6.1: Verify subscription status
  ├─ 6.2: Verify free services
  └─ 6.3: Complete MFA setup (mandatory)
        └─ Error: MFA required → Set up Authenticator/SMS/Phone
```

## Common Global Errors (Can Occur at Any Step)

| Error | Cause | Fix |
|---|---|---|
| "Something went wrong" (generic) | Azure backend issue | Wait and retry. Check [Azure Status](https://status.azure.com/). |
| "Too many requests" (HTTP 429) | Rate limiting due to rapid retries | Wait 5-15 minutes before trying again |
| Browser compatibility issues | Outdated browser or unsupported browser | Use the latest version of Microsoft Edge, Google Chrome, or Mozilla Firefox |
| Network timeout | Unstable internet connection | Switch to a stable network |
| "Session expired" | Took too long on one step | Refresh the page and sign in again |
| MFA enforcement (citation:1) | Since October 2024, MFA is mandatory for all Azure/admin portal sign-ins | Must complete MFA setup; no way to bypass |
